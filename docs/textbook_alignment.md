# 教材对齐说明

参考材料：《Business AI Data Structures and Analytics》提取页（2025年1月）。本文件仅记录可从所给 8 页内容直接观察到的方法启示，不将其扩展为未出现的教材观点。

1. 年报抓取应明确表单类型、标识符、起止日期、下载目录及用户代理，并对 HTTP 响应调用状态检查。
2. 下载文件应以公司标识、报告类型和日期组织，避免覆盖；本项目用 `source_registry.csv` 的 `source_id`、本地路径和 SHA-256 实现这一点。
3. 章节提取应以可复核的原始文本为输入。本项目保留 `page_start`、`page_end` 与 `extraction_note`，并要求人工复核自动窗口切分。
4. 数据收集必须验证输入日期和实体标识。项目的 `validate_sources.py` 检查 URL、日期、公司代码对应关系和重复记录。

限制：所给提取页主要是美国 SEC 年报下载和章节解析代码，不包含中国 A 股分类标准、基金选股池或招聘文本标注方法。因此这些问题另用中国官方披露材料与项目预先定义的规则处理。
