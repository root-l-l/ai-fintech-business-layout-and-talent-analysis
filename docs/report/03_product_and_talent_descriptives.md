# 3 产品证据与人才需求描述性分析

## 3.1 产品页证据的使用方式

研究者提供了覆盖全部 15 家样本公司的产品页链接。产品页用于补充年报中较为概括的业务披露，尤其用于定位具体产品、服务对象与业务场景。链接覆盖率不等于产品信息完整性：后续文本分析仅能将已保存的页面原文和年报原文作为语料；链接本身只承担来源定位功能。

## 3.2 招聘样本的描述性边界

清洗后职位样本为 242 条，覆盖全部 15 家公司。该样本中同花顺的记录数明显多于其他公司，因此跨公司比较应同时报告样本量，不宜仅按职位数或AI词汇命中数对公司排序后推断招聘强度。

本文将“AI相关技术栈要求”字段中出现预先声明词典关键词且不属于“无明确要求”等空缺表达的职位记录标记为“含AI相关文字记录”。这一标记只表示招聘原文的可见措辞，不能等同于岗位的AI工作占比、公司AI人才比例或技术成熟度。

## 3.3 关键词统计口径

对职位名称、技能要求及AI技术栈字段进行字面匹配，按职位-关键词计数：同一职位即使多次出现同一关键词，也只计一次。统计结果见 `outputs/tables/recruitment_skill_keyword_counts.csv`，它可作为报告图表的数据来源；所有图注需注明“基于本次导入的242条去重招聘记录”。
